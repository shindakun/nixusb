# niri (scrollable-tiling Wayland compositor) + Noctalia (the desktop shell).
# Install:  pacman -S --needed - < niri.txt
#
# Noctalia provides the bar, launcher, notifications, lock screen, idle
# handling, wallpaper, clipboard history, OSD, and polkit agent, so none of
# the usual separate tools (waybar, fuzzel, mako, swaylock, swayidle, swaybg)
# are installed.
#
# niri has no built-in XWayland. It starts xwayland-satellite itself when an
# X11 app connects, as long as the binary is on PATH.

niri
xwayland-satellite
# Noctalia v5 (native). The Air runs v4 (noctalia-shell, Quickshell-based),
# which Arch does not package at all, so the two machines differ here and only
# here: config.kdl includes a per-distro shell.kdl that spawns the right one.
noctalia

# ---- session / portals ----
xdg-desktop-portal
xdg-desktop-portal-gtk
xdg-desktop-portal-gnome
gnome-keyring
libnotify

# ---- launcher ----
# The shared niri config binds Mod+D to wofi (matching the Air). Noctalia has
# its own launcher too; swap the bind in nix/home/niri/config.kdl if you prefer
# it on both machines.
wofi

# ---- terminal ----
kitty

# ---- screenshots / clipboard (CLI) ----
grim
slurp
wl-clipboard

# ---- display manager ----
# greetd + tuigreet: light, works cleanly with Wayland sessions.
greetd
greetd-tuigreet

# ---- file manager / misc GUI ----
nautilus
brightnessctl
playerctl
